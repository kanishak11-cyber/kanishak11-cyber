## `01` About

> **I build for builders.**

I'm a founder and developer-relations builder from Ghaziabad, India. I run **[FLUXOR](https://www.fluxor.io)**, a hackathon platform that grew into a small ecosystem, and I build the AI agents and Web3 products behind it.

Before FLUXOR I founded PolyCrypt HQ and built **[BlockPen](https://blockpen.xyz)**, an on-chain document-signing platform. I shipped production smart contracts at Digi195 and built full-stack features at Hackingly. These days I also write and speak about agentic AI, developer tooling and Web3.
